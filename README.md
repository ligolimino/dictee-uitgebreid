# Letterlab — uitgebreid dictee

Zelfstandige dicteetool met eigen woordaudio en afbeeldingen. De cursistenpagina
staat rechtstreeks op de hoofdlink. De lesgeverspagina staat onder `beheer/`.

## Publiceren

Maak op GitHub een openbare repository `dictee-uitgebreid` en upload de
**inhoud** van deze map. Schakel GitHub Pages in via `main` en `/ (root)`.

- Cursisten: `https://gebruikersnaam.github.io/dictee-uitgebreid/`
- Beheer: `https://gebruikersnaam.github.io/dictee-uitgebreid/beheer/`

## Overstappen

Publiceer en test deze repository eerst. Vervang daarna de bestaande links in
Genially. Verwijder de oude gecombineerde repository pas wanneer alle vervangen
links op pc, Android en iPhone werken.
